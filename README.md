# NovaLearn Academy — React + Vite Demo

Premium dark navy education website demo with glassmorphism, floating UI, animations and responsive layouts.

Includes:
- Admissions / online application modal
- Academics and courses
- Early Years, Primary, Middle and Senior School
- Tech and Sports Academy courses
- Fee structure
- Notice board / announcements
- Faculty & staff
- Student life
- Student / Parent portal demo
- Campus visit CTA
- WhatsApp admissions CTA
- Program filters
- Mobile navigation
- Glass gradients, floating cards and animated hero

Run:
npm install
npm run dev

Build:
npm run build

Images are remote demo images. For a real client website, replace them with licensed/client-owned assets.
